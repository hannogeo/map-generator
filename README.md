# Map Generator

A fast, low-memory desktop app for generating street-level panorama locations inside GeoJSON polygons.

This project was hugely inspired by [various-map-generator](https://various-map-generator.pages.dev/). This is a native desktop take on it: a parallel Rust backend, built-in country polygons and automatic updates.

## What it does

- Pick one or more countries or territories (or draw your own polygon / import GeoJSON) on the map.
- Generate random panorama locations inside them using Google Street View and 13 other providers.
- Filter by camera generation, blue lines, road type, date, altitude, links, description, author and more.
- Find new drops. When a road is re-captured, Google keeps returning the original panorama from spatial search, so the app follows the old panorama's timeline to the newer captures.
- Export the results as JSON or CSV, or copy them to the clipboard.
- Blue-line overlays show where street view coverage exists.
- Click any generated pin to open its panorama in the browser.

## Supported providers

Google, Apple, Yandex, Bing, Naver, Kakao, Baidu, Tencent, Mapillary, Mapy.cz, ASIG, Já360, Vegbilder, OpenMap.

## How to use it

1. **Select areas.** Click countries on the map, search for them in the list, or draw/import your own polygon.
2. **Set a goal.** Each selected area shows how many locations you want from it (default 1000).
3. **Choose a provider and filters.** Pick the street-view provider and tune the filters (camera generation, dates, blue lines, etc.).
4. **Generate.** Click *Start generation*. Pins appear on the map as locations are found. Click a pin to open its panorama.
5. **Export or reset.** Use *Export* to save your locations (JSON/CSV/copy), or *Reset* to clear everything and start over (settings are kept).

## Settings

Everything is saved automatically and persists between sessions: provider, radius, strategy (random/grid), number of generators, speed, ocean-sample filtering, filters, notification preferences and more. Use *Reset* to clear found locations while keeping the selected countries and your settings.

## Notifications

Optional desktop (and Discord webhook) notifications when a location is found, a polygon is complete, or all polygons are complete.

## Performance

Generation runs in the Rust backend with parallel sampling, so it's **around 4× faster** than the browser-based version with the same settings, while using noticeably less RAM. The UI is a thin webview (Tauri), so the app stays lightweight.

Measured on the same machine and network, Google provider, Estonia, 5 generators × 1000 attempts, target of 300 locations (median of 3–5 runs):

| Scenario | Map Generator | Browser (various-map-generator.pages.dev) | Speedup |
|---|---|---|---|
| Default filters (random) | 0.8 s | 3.0 s | 3.8× |
| Gen 4 only | 1.3 s | 5.5 s | 4.2× |
| No generation filter | 0.9 s | 4.1 s | 4.6× |

The Rust side keeps a single pooled HTTP/2 client, caps concurrency at 128 requests, skips sea samples locally with an embedded 140 KiB land mask (toggleable, and auto-disabled per generator for tiny islands), and drops the redundant second Google request (SingleImageSearch is byte-identical to GetMetadata). The land mask is generated by `scripts/build-land-mask.mjs` from Natural Earth 1:50m. The browser version issues one request per sample with no local land check.
